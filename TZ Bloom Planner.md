# Техническое задание
# 🌷 Bloom — милый планер для учёбы

> Дипломный проект по курсу: Python Base · SQL Database · Django MVT · Django REST Framework

---

## 1. Общая идея

**Bloom** — веб-планер для студентов в нежном «девчачьем» стиле: розовая палитра, рукописный шрифт, сердечки вместо чекбоксов. Он помогает:

- составить **план на месяц** и разбить его на недели и дни;
- вести **учебные предметы**, дедлайны и экзамены;
- отслеживать **привычки** (вода, спорт, чтение, слова на иностранном);
- учиться по **таймеру Помодоро** и видеть, сколько часов ушло на каждый предмет;
- в конце недели делать **рефлексию**: настроение, что получилось, что перенести.

**Главная фишка — «сад»:** каждая выполненная задача поливает цветок месяца. Чем больше сделано, тем пышнее он цветёт: 🌱 → 🌿 → 🌷 → 💐. В конце месяца сохраняется «букет», и в профиле копится коллекция букетов за все месяцы.

## 2. Роли пользователей

| Роль | Возможности |
|---|---|
| Гость | Видит лендинг, может зарегистрироваться или войти |
| Пользователь | Полный доступ только к своим данным: планы, задачи, предметы, привычки, таймер, статистика |
| Администратор | Django Admin: пользователи, справочники (иконки, цветы, цитаты дня) |

Пользователь **никогда** не видит и не меняет чужие данные. Это проверяется на уровне permissions и queryset.

## 3. Функциональные модули

### 3.1 Аккаунт
- Регистрация, вход, выход (сессии для сайта, токен для API).
- Профиль: имя, аватар, любимый цвет-акцент (розовый / лавандовый / персиковый), цель на семестр.

### 3.2 План на месяц 🗓️
- Создать месяц: название («Ноябрь — сессия!»), главная цель месяца, до 3 фокус-целей.
- Календарная сетка месяца: в каждой клетке точки-сердечки по количеству задач на этот день.
- Клик по дню открывает задачи дня.
- Прогресс месяца — процент выполненных задач, полоса в виде растущей лианы.

### 3.3 Задачи (To-do) 💗
- Поля: название, описание, дата, приоритет (🌸 низкий / 🌷 средний / 🌹 высокий), предмет (необязательно), статус.
- Пиксельное сердечко-чекбокс: пустое ♡ → закрашенное ♥ с анимацией.
- Удаление крестиком ✕, редактирование по клику.
- Перенос невыполненной задачи на завтра одной кнопкой.
- Фильтры: сегодня / неделя / просроченные / по предмету / по приоритету.

### 3.4 Учёба 📚
- **Предметы:** название, цвет-метка, преподаватель, кабинет.
- **Дедлайны и экзамены:** тип (экзамен / зачёт / курсовая / ДЗ), дата, предмет.
- Виджет **«Обратный отсчёт»**: «До экзамена по SQL осталось 12 дней 🌷».
- **Расписание недели:** сетка пн–сб с парами.

### 3.5 Трекер привычек ✨
- Пользователь создаёт привычку: «Выпить 8 стаканов воды», «20 французских слов», «Зал».
- Отметка по дням: сетка месяца, выполненные дни — закрашенные сердечки.
- Серия (streak): «🔥 7 дней подряд!».

### 3.6 Помодоро-таймер ⏳
- Таймер 25/5 минут (можно настроить), привязка к предмету.
- По завершении сессия сохраняется в БД.
- Статистика: сколько часов за неделю на каждый предмет (кольцевой график).

### 3.7 Рефлексия недели 💌
- Раз в неделю форма: настроение (5 эмодзи), «Чем горжусь», «Что не получилось», «Что переношу».
- Лента прошлых рефлексий в стиле дневника.

### 3.8 Сад и букеты 🌸 (фишка)
- Цветок текущего месяца растёт по стадиям в зависимости от % выполненных задач:
  - 0–24% — 🌱 росток
  - 25–49% — 🌿 стебель
  - 50–79% — 🌷 бутон
  - 80–100% — 💐 букет
- В конце месяца стадия фиксируется, и букет попадает в коллекцию «Мой сад».

### 3.9 Дашборд «Сегодня» 🏠
Главная страница после входа:
- приветствие + цитата дня;
- задачи на сегодня;
- ближайший дедлайн с обратным отсчётом;
- привычки на сегодня;
- цветок месяца;
- кнопка «Начать помодоро».

## 4. Модели базы данных

```
User (стандартный Django)
 └── Profile           user(1:1), avatar, accent_color, semester_goal

                       final_stage (null до конца месяца)
                       unique_together: (user, year, month)

                       title, description, date, priority(low/mid/high),
                       is_done, done_at, created_at

Deadline               user(FK), subject(FK), title,
                       kind(exam/test/coursework/homework), due_date

ScheduleSlot           user(FK), subject(FK), weekday(0–5), start_time, end_time

Habit                  user(FK), title, emoji, is_active
HabitCheck             habit(FK), date
                       unique_together: (habit, date)

PomodoroSession        user(FK), subject(FK, null), started_at, duration_min

WeeklyReflection       user(FK), week_start, mood(1–5),
                       proud_of, failed, carry_over
                       unique_together: (user, week_start)

Quote (справочник)     text, author
```

## 5. REST API (DRF)

Базовый префикс: `/api/v1/`. Все эндпоинты, кроме auth, требуют авторизации.

### Auth
| Метод | URL | Описание |
|---|---|---|
| POST | `/auth/register/` | Регистрация |
| POST | `/auth/token/` | Получить токен |
| GET/PATCH | `/profile/` | Свой профиль |

### План и задачи
| Метод | URL | Описание |
|---|---|---|
| GET/POST | `/months/` | Список месяцев / создать |
| GET/PATCH/DELETE | `/months/{id}/` | Один месяц |
| GET | `/months/{id}/calendar/` | Задачи по дням (для сетки) — `@action` |
| GET | `/months/{id}/garden/` | Процент выполнения и стадия цветка — `@action` |
| GET/POST | `/tasks/` | Список (фильтры: `date`, `subject`, `priority`, `is_done`) / создать |
| PATCH/DELETE | `/tasks/{id}/` | Изменить / удалить |
| POST | `/tasks/{id}/toggle/` | Отметить или снять сердечко |
| POST | `/tasks/{id}/move-tomorrow/` | Перенести на завтра |
| GET | `/tasks/today/` | Задачи на сегодня |

### Учёба
| Метод | URL | Описание |
|---|---|---|
| CRUD | `/subjects/` | Предметы |
| CRUD | `/deadlines/` | Дедлайны (сортировка по дате) |
| GET | `/deadlines/upcoming/` | Ближайшие 3 с количеством дней до них |
| CRUD | `/schedule/` | Расписание |

### Привычки, таймер, рефлексия
| Метод | URL | Описание |
|---|---|---|
| CRUD | `/habits/` | Привычки |
| POST | `/habits/{id}/check/` | Отметить день (повторный вызов снимает отметку) |
| GET | `/habits/{id}/streak/` | Текущая серия |
| GET/POST | `/pomodoro/` | Сессии |
| GET | `/pomodoro/stats/?period=week` | Минуты по предметам (агрегация) |
| CRUD | `/reflections/` | Рефлексии |

### Дашборд
| Метод | URL | Описание |
|---|---|---|
| GET | `/dashboard/` | Всё для главной одним запросом |

### Технические требования к API
- `ModelViewSet` + `DefaultRouter`.
- Permission `IsOwner`: доступ только к своим объектам; `get_queryset()` фильтрует по `request.user`.
- Проверка в сериализаторах: нельзя привязать задачу к чужому предмету или месяцу.
- Фильтрация через `django-filter`, поиск по `title`, сортировка по `date` и `priority`.
- Пагинация задач — 20 на страницу.
- Документация Swagger через `drf-spectacular` по адресу `/api/docs/`.
- Статистика считается в БД (`annotate`, `Count`, `Sum`, `TruncDate`), а не циклами в Python.

## 6. Фронтенд

### 6.1 Технологии
- Django-шаблоны (MVT): `base.html` + страницы.
- Vanilla JS (`fetch`) для действий без перезагрузки: отметить задачу, добавить, удалить, таймер.
- Chart.js (CDN) для графиков.
- Без сборщиков и фреймворков.

### 6.2 Страницы
| URL | Страница |
|---|---|
| `/` | Лендинг для гостя: большой заголовок, цветы, кнопка «Начать цвести 🌷» |
| `/login/`, `/register/` | Формы в карточке с сердечками |
| `/today/` | Дашборд «Сегодня» |
| `/month/` | Календарь месяца + цветок + цели |
| `/tasks/` | To-do в стиле макета (см. ниже) |
| `/study/` | Предметы, дедлайны, расписание |
| `/habits/` | Сетка привычек |
| `/focus/` | Помодоро-таймер + статистика |
| `/diary/` | Рефлексии |
| `/garden/` | Коллекция букетов по месяцам |

### 6.3 Дизайн-система (по присланному макету)

**Цвета**
```css
:root {
  --bg:          #F8ECEA;  /* фон страницы */
  --card:        #FDD5CE;  /* карточка */
  --input:       #FFB5A7;  /* поле ввода */
  --accent:      #FF0080;  /* кнопки, активные элементы */
  --accent-dark: #A8002E;  /* тёмное сердце, высокий приоритет */
  --soft-pink:   #F48FA0;  /* светлое сердце */
  --text:        #1A1A1A;
  --muted:       #7A6A6A;  /* плейсхолдеры, ✕ */
}
```

**Шрифты (Google Fonts)**
- Заголовки и текст: `Gochi Hand` или `Patrick Hand` (рукописный, как в макете).
- Цифры таймера и статистики: `Quicksand` (для читаемости).

**Компоненты**
- **Карточка:** `border-radius: 16px`, мягкая тень, фон `--card`. Сверху три «наклейки»-сердечка (светлое, среднее, тёмное), которые заходят за край карточки.
- **Поле + кнопка:** одна капсула `border-radius: 999px`; поле `--input`, кнопка `--accent` с белым текстом.
- **Чекбокс:** пиксельное сердечко (SVG). Пустое ♡ → залитое `--accent` ♥, анимация «пульс» 0.3 с.
- **Выполненная задача:** текст зачёркнут, прозрачность 0.5.
- **Удаление:** серый ✕ справа, при наведении становится `--accent`.
- **Заголовки** с эмодзи-акцентом: «To-do List 🌷», «My Month 🗓️», «Habits ✨».
- **Микроанимации:** конфетти из сердечек при выполнении всех задач дня; цветок плавно «подрастает» при смене стадии.
- **Адаптивность:** mobile-first, на телефоне меню снизу (5 иконок).

## 7. Нефункциональные требования
- Python 3.11+, Django 5.x, DRF 3.15+.
- БД: SQLite для разработки, PostgreSQL для продакшена.
- Секреты в `.env` (`python-decouple` или `django-environ`).
- Тесты (`APITestCase`), минимум:
  - пользователь A не видит задачи пользователя B;
  - `toggle` меняет `is_done` и `done_at`;
  - стадия цветка считается правильно на границах 24/25/49/50/79/80%;
  - streak привычки считается правильно с пропуском дня;
  - нельзя создать два месяца с одинаковыми `year` и `month`.
- Фикстура с демо-данными: `python manage.py loaddata demo.json`.
- `README.md` с инструкцией запуска и скриншотами.

## 10. Сценарий защиты (5 минут)
1. Лендинг → вход под демо-пользователем.
2. Дашборд «Сегодня»: отмечаю задачу сердечком, цветок месяца подрастает.
3. Календарь месяца, обратный отсчёт до экзамена.
4. Запускаю помодоро (на защите — короткий режим 10 секунд), показываю график по предметам.
5. Переключаюсь на Swagger: тот же `POST /tasks/{id}/toggle/` вручную.
6. Показываю тест «чужие задачи недоступны» и запускаю `python manage.py test`.
7. Финал: страница «Мой сад» с букетами за прошлые месяцы 💐
